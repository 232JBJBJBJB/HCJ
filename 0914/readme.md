## 1. 모바일 청첩장
스마트폰 환경에 최적화된 클래식하고 세련된 모바일 청첩장입니다.

* 핵심 기능: D-DAY 실시간 카운트다운, 스와이프 가능한 갤러리 섹션, 오시는 길(지도) 표시
* 커스텀 포인트 (Personal Touch):
  * 클래식 웨딩 무드: 일반적인 야외 스냅 대신, 정통 쓰리피스 턱시도와 앤틱한 호텔 느낌의 스냅 사진을 배치하여 고급스러운 분위기 연출.
  * 맞춤형 테마: 전체적인 배경 톤을 연한 하늘색(`#7da4c4`)으로 맞추고, 이에 어울리는 커스텀 지도 SVG를 직접 생성하여 이질감 없이 삽입.

## 2. Smart QR
URL을 입력하면 즉시 QR 코드로 변환해 주고 다운로드할 수 있는 웹 앱입니다.

* 핵심 기능: URL 입력 시 하단에 QR 코드 즉시 생성, 생성된 QR 코드 클릭 시 JPG 다운로드
* 커스텀 포인트 (Personal Touch):
  * 동적 그라데이션 인터랙션: 마우스 커서의 움직임을 추적하여 연한 하늘색 빛이 커서를 따라다니는 감성적인 배경 효과 구현.
  * 테마 전환 기능: 우측 상단에 '기기 설정 / 화이트 모드 / 다크 모드'를 선택할 수 있는 탭을 추가하여 사용자 환경 최적화.
  * 커스텀 로고: 테마와 어울리는 '비 내리는 구름' 모양의 SVG 로고 제작 및 적용.

## 3. 문서 용량 압축기
브라우저 내에서 안전하게 문서와 이미지의 용량을 줄여주는 보안 특화 압축기입니다.

* 핵심 기능: 파일 드래그 앤 드롭 업로드, 개별 파일 압축 진행 상태(프로그레스 바) 표시, 브라우저 로컬 처리(서버 전송 없음)
* 커스텀 포인트 (Personal Touch):
  * 복잡한 규격 파일 우회 처리: HWP 업로드 시 변환 요청 알림창을 띄우고, PDF 업로드 시 "저화질 스캔본 형태로 우회 압축 진행" 안내창을 띄우는 실무적인 예외 처리 로직 적용.
  * 시스템 테마 강제 적용: 별도의 버튼 없이 사용자 기기(OS)의 다크 모드 설정을 무조건 따르도록 CSS 미디어 쿼리(`prefers-color-scheme`) 적용 (짙은 네이비 블루 테마).
  * UI 디테일: 드롭존에 파일을 올릴 때 파란색으로 반짝이는 펄스(Pulse) 애니메이션 추가 및 확장자별(PDF, DOC, PPT, IMG) 맞춤형 컬러 아이콘 적용. 시원한 바다 파도 모양의 로고(`logo_ocean.svg`) 적용.

## 4. 이미지 일괄 리사이즈
여러 장의 이미지를 한 번에 원하는 비율과 크기로 변환하고 압축 파일로 다운로드하는 도구입니다.

* 핵심 기능: 캔버스 비율(1:1, 16:9 등) 및 크기 조절, 패딩/크롭 모드 지원, 작업 완료 후 ZIP 파일 일괄 다운로드
* 커스텀 포인트 (Personal Touch):
  * 브랜드 아이덴티티 구축: 가상의 기업 '빈빈컴퍼니'를 설정하여 시그니처 다크 네이비와 블루 포인트 컬러를 적용. 알파벳 'B'를 형상화한 모던한 전용 로고(`logo_binbin.svg`) 적용.
  * 전문적인 레이아웃 분할: 좌측에는 파일을 쉽게 던져 넣을 수 있는 큼직한 드롭존, 우측에는 상세 옵션을 직관적으로 제어할 수 있는 컨트롤 패널을 배치하여 작업 효율 상승.

## 5. GIF 동영상 생성기
무거운 편집 프로그램 없이 브라우저에서 동영상을 GIF로 변환해 주는 가벼운 웹 앱입니다.

* 핵심 기능: MP4 등 동영상 파일 업로드, 29FPS 제한을 통한 최적화 변환, 완료 후 GIF 다운로드
* 커스텀 포인트 (Personal Touch):
  * 'Jing' 브랜드 런칭: 자연 친화적인 연한 초록색(민트 그린) 그라데이션 테마를 베이스로 설정.
  * 전용 디자인 요소: 초록빛 잎사귀 모티브를 활용한 'Jing' 전용 로고(`logo_jing.svg`)를 직접 디자인하여 삽입.

## 6. GIF 편집 스튜디오
GIF 파일의 크기, 속도, 프레임 등을 직접 수정할 수 있는 다기능 에디터입니다.

* 핵심 기능: 초기 업로드 화면과 편집 스튜디오 화면의 동적 전환, 원본 GIF 메타데이터(용량, 프레임, FPS 등) 추출 및 표시, 9가지 편집 도구(Resize, Crop, Speed 등) 패널 제공
* 커스텀 포인트 (Personal Touch):
  * 통일성 있는 UX: 이전 'GIF 동영상 생성기'와 동일한 'Jing' 브랜드의 초록색 그라데이션 배경과 로고를 공유하여 서비스의 연속성 부여.
  * 단계별 뷰 전환: 파일 업로드 시 초기 화면이 사라지고 좌측 미리보기, 우측 도구 모음 형태의 2단 스튜디오 레이아웃으로 부드럽게 전환되도록 사용자 경험 설계.
