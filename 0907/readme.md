# 釜山観光ガイド (Busan Tourism Web Guide)

釜山、新たな魅力を発見する旅へ。
Tailwind CSS와 Vanilla JavaScript를 활용하여 구현한 반응형 釜山 観光(부산 관광) 랜딩페이지입니다.

---

## 📌 프로젝트 개요 (Overview)

본 프로젝트는 일본 관광객을 타겟으로 한 부산 관광 안내 Landing Page입니다.
부산의 대표 명소, 엑티비티, 먹거리를 세련된 디자인과 직관적인 UI/UX로 소개해, 사용자가 매끄럽고 몰입감 있게 웹사이트를 탐색할 수 있도록 제작되었습니다.

---

## ✨ 핵심 기능 (Key Features)

* 모던 UI/UX & 애니메이션
  - 히어로 섹션의 미세한 Zoom-out 배너 애니메이션 적용
  - 스크롤 유도를 위한 커스텀 Scroll Line 애니메이션 적용
  - 카드 호버 시 부드러운 상향 이동 및 그림자 효과
* 스마트 인터랙티브 네비게이션
  - 스크롤 감지를 통해 상단 스크롤 위치에 따라 바 배경이 반투명에서 흰색으로 자연스럽게 전환
  - CSS scroll-smooth를 활용한 Smooth Scrolling 구현
* 완벽한 반응형 웹 (Responsive Design)
  - Grid 시스템 기반 Layout (Desktop 4열/2열, Mobile 1열 자동 대응)
* 멘탈 모델에 맞춘 카테고리 기획
  - どこへ行く？ (어디로 갈까?): 해운대, 광안리, 감천문화마을, 태종대
  - 何をする？ (무엇을 할까?): 요트 투어, 블루라인 파크 스카이 캡슐
  - 食べる (무엇을 먹을까?): 돼지국밥, 자갈치 시장 해산물

---

## 🛠 사용 기술 스택 (Tech Stack)

* Frontend: HTML5, JavaScript (ES6+)
* Styling: Tailwind CSS (CDN Config), CSS Keyframe Animations
* Typography: Google Fonts (Inter, Noto Sans JP)
* Assets: Unsplash High-Resolution Images

## 🚀 실행 방법 (Getting Started)

별도의 라이브러리 설치나 빌드 과정 없이, 단일 HTML 파일로 즉시 실행할 수 있습니다.

1. 본 저장소를 클론(Clone)하거나 index.html 파일을 다운로드합니다.
2. index.html 파일을 브라우저(Chrome, Edge 등)로 실행합니다.
