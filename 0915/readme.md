## 1. 오늘의 운세
사용자의 생년월일, 성별, 그리고 5가지 오행 원소를 선택하여 오늘의 운세를 확인할 수 있는 웹 앱입니다.

* 핵심 기능: 이름, 생일, 나이, 성별 입력 및 5가지 원소(불, 물, 나무, 땅, 바람) 선택에 따른 맞춤형 랜덤 운세 출력
* 커스텀 포인트 (Personal Touch):
  * 브랜딩: 좌측 상단 헤더에 'Been' 컴퍼니 명칭 적용.
  * 디자인: 애플 스타일의 깔끔한 폰트와 부드러운 UI 레이아웃 구성.

## 2. 글자 수 세기
입력한 텍스트의 글자 수, 바이트 수, 공백 제외 글자 수를 실시간으로 계산해 주는 유틸리티입니다.

* 핵심 기능: 텍스트 입력 시 실시간 통계 계산 (영/숫자는 1바이트, 한글은 2바이트 계산 로직 적용)
* 커스텀 포인트 (Personal Touch):
  * 테마: 연한 하늘색 그라데이션 배경 적용.
  * 아이덴티티: 이미지 로고 없이 텍스트 중심의 미니멀한 'Been' 헤더 구성.

## 3. 문서 파일 통계 분석 시스템

## 7. Keep Fit! BMI 계산기
사용자의 신체 정보를 기반으로 BMI를 측정하고, 목표 체중 기준에 따른 맞춤형 분석을 제공하는 건강 앱입니다.

* 핵심 기능: 성별, 키, 몸무게 입력에 따른 BMI 수치 및 등급 산출, 표준 체중의 90%, 100%, 110% 기준 감량/증량 필요 수치 계산
* 커스텀 포인트 (Personal Touch):
  * 테마: 벚꽃색 그라데이션 테마 적용.
  * UI/UX: 직관적인 상태 뱃지와 타겟 분석 리스트 카드 구성.

## 10. 오디오 파일 편집 시스템
